About Clewbook

Fundraisers and auctions on Zcash. Pay privately, hold a refund ticket, check the books yourself.

Who runs it

Clewbook is an independent open source project, built by one developer so far. We run these pages, the relay that stores the campaigns' public lists, the listing that picks the campaigns on the home page, and the testnet demo. The code is public on GitHub.

Each campaign is run by its host. The host holds the campaign's money until the close; Clewbook holds money only for the campaigns it hosts itself. What is different: every contributor holds a refund ticket, and anyone can recount the host's books against the Zcash chain.

What we plan next is on our roadmap.

Contact

Open an issue on GitHub (this needs a GitHub account). To host a campaign with us, use Host with us.

Terms, in plain words

  • These pages and the code are offered as they are. We make no promise that they work without faults, or that a campaign reaches its goal or delivers what it describes.
  • A campaign's host decides what it is for, holds its money and answers for it. A campaign on our home page means we approved its host's key, not that we checked the campaign.
  • Your refund ticket works without us and without the host, while your contribution is unspent.
  • We can hide a campaign or a host from the home page at any time. That deletes nothing from a relay, and the campaign's own links keep working.
  • Test network coins (TAZ) have no value.
  • The code is licensed under MIT or Apache 2.0, at your choice.

Privacy, in plain words

  • No account, no cookies, no analytics or tracking on these pages. Your name is never asked for.
  • Kept in your browser only: the secret behind your payment code, your refund ticket, and small settings (theme, layout, the network you picked). We never receive them. Your backup file holds the same secret, so keep it private.
  • Our page server writes no log of requests. The relay counts requests per network address in memory, to limit abuse. The listing keeps the network address that sent each listing request, to limit requests from hosts not yet approved.
  • Our pages, the relay and the listing are reached through Cloudflare, which sees that traffic. The public Zcash servers your page asks for blocks and transactions see your network address and what it asks for; some of those requests pass through our page server on the way.
  • What is public about a campaign: its rules and its signed list. A fundraiser shows each amount. An auction shows every bid after the close. A blind bid auction shows every bid and every refund address after the close. In other campaigns your refund address is published only if you choose to publish proof for a payment the host set aside.
