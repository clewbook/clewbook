What a ticket does, plainly
✓Returns your payment minus the network fee (0.0001 ZEC).
✓Works without the host.
!Only on the Zcash network version it was signed for. After an upgrade the host has to issue it again.
!If a host spends a ticketed payment, Recount shows it in red with the transaction. That catches it after the fact. It does not stop it.
